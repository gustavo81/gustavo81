# Calven · versión de prueba

Calendario Android para registrar vencimientos desde fotografías, revisar las fechas detectadas y configurar recordatorios.

## Descargar en Android

[**Descargar Calven 0.1.0 (APK de prueba)**](https://github.com/gustavo81/gustavo81/raw/refs/heads/main/Calven-0.1.0-debug.apk)

1. Abrir el enlace desde el teléfono y descargar el archivo.
2. Abrirlo desde Descargas. Si Android lo solicita, permitir la instalación desde el navegador o gestor de archivos utilizado.
3. Instalar Calven, abrirla y habilitar las notificaciones.

Requiere Android 8.0 o posterior. No funciona en iPhone.

Es una compilación de desarrollo, firmada con una clave de depuración. La compilación, las 10 pruebas de lógica y Android Lint pasaron; cámara, OCR y recepción de avisos todavía requieren validación en un teléfono real. Los avisos son notificaciones sonoras con horario aproximado y dependen de los permisos y ajustes de Android.

La primera versión permite revisar y guardar un vencimiento a la vez. Aún no interpreta automáticamente las filas de una planilla para importar múltiples vencimientos.
